## Usage

Optional: Register the cube's face colors with keys 1 - 6.

Save each of the cube's faces with Space.

If none of the colors have been misrecognized, the possible cube configurations will be printed to stdout.

## Keys

Keys 1 through 6: Select Rubik's cube colors. The camera's center pixel is sourced and registered as one of the cube's colors. (white, yellow, red, orange, blue, green)

Space: Source the cube's face and save it for reconstruction.

S: Save image.
